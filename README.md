# Bank Management System (C++)

## About The Project

Bank Management System is a console-based application developed using C++. It simulates basic banking operations and provides features for managing customer accounts, handling transactions, and managing loans.

The project demonstrates practical implementation of C++ programming concepts through a banking system.

## Features

- Create New Bank Accounts
- View Account Details
- Update Account Information
- Close Bank Accounts
- Deposit Money
- Withdraw Money
- Transfer Funds
- Check Account Balance
- Loan Management
- Loan Repayment
- Interest Calculation
- PIN Verification and Recovery
- Password Reset
- Freeze and Unfreeze Accounts
- Admin Panel
- Read-Only Admin Access

## Technologies Used

- C++
- Standard Template Library (STL)
- Console-Based Interface
- Windows Console Support

## Core Concepts

- Object-Oriented Programming
- Functions
- Conditional Statements
- Loops
- Data Management
- User Input Validation

## How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio or a compatible C++ IDE.
3. Compile the C++ source file.
4. Run the application.

**Note:** This application uses temporary in-memory storage. Account data is not permanently saved after the program closes. It is designed as a learning project.

## Project Purpose

This project was developed to strengthen C++ programming skills, understand banking operations, and practice building a real-world-inspired console application.
